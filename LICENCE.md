## 🧩 About

**Elden Ring helpers** is a curated list of Elden Ring open-source tools:

- **Overlays** — on-screen helpers, layout notes, hitbox viewer, stat displays
- **Quality-of-Life Helpers** — item catalog, build planner, map notes
- **Research Notes** — boss strategies and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Gameplay Helpers
- Boss Timer — track attack patterns and phase timings
- Hitbox Viewer — visualize enemy hitboxes for study
- Damage Log — record incoming and outgoing damage
- Speed Control — adjust game speed for study (0.1x to 2x)

### 🎨 Catalog & Cosmetics
- Item Catalog — browse weapons, armor, talismans, ashes
- Build Planner — organize stats and equipment
- Map Overlay — show collected sites of grace and dungeons

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any boss
- Gravity Control — adjust jump height for platforming study
- Stamina Buffer Notes — chain complex maneuvers in the editor
